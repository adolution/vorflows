Zusatz-Schritt für ErstnutzerAuf Loom ansehen ↗

Du hast VS Code und Claude Code wie im Tutorial installiert, bekommst aber bei der ersten Eingabe eine rote Fehlermeldung (z. B. „claude is not recognized“ oder „You must run claude to review the updated terms“)? Dann muss Claude nur einmalig freigeschaltet werden, das dauert zwei Minuten. Schau dir bei Bedarf einmal das Video an.

Nur falls eine Fehlermeldung bereits bei deiner ersten Eingabe erscheint, führ diese Schritte aus:

  1. Terminal öffnen. In VS Code oben im Menü auf Terminal, Neues Terminal. Unten erscheint ein Eingabefeld.
  2. Claude installieren. Kopier die Zeile für dein Gerät, klick ins Terminal, füg sie ein, drück Enter. Danach das Terminal einmal schließen und neu öffnen.
    Windowsirm https://claude.ai/install.ps1 | iex
    Maccurl -fsSL https://claude.ai/install.sh | bash
  3. Einrichtung komplett durchklicken. Tipp claude ins Terminal, Enter. Jetzt die kurze Einrichtung ganz zu Ende machen, nicht abbrechen: zuerst ein Design mit den Pfeiltasten wählen (z. B. „Dark mode“) und Enter, dann im Browser anmelden, danach die Nutzungsbedingungen mit Enter bestätigen. Warte, bis unten eine normale Eingabezeile erscheint (Claude ist dann bereit), und schließ erst dann das Terminal.

Wichtig: Brichst du die Einrichtung ab oder schließt das Terminal zu früh, kommt dieselbe Meldung wieder. Im Browser-Login oder in der Claude-Desktop-App zu bestätigen reicht nicht, es muss in Claude Code selbst passieren. Mehr unter Hilfe bei Fehlern.
